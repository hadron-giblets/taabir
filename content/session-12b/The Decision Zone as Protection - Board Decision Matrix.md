# The Decision Zone as Protection: Board Decision Matrix

A decision zone chart maps out in advance which decisions belong to which people or bodies, so that authority doesn't have to get renegotiated every time a question comes up. It protects people from the exhausting default of needing to be present for every decision, and it protects the organization from decisions quietly defaulting to whoever happens to be in the room.

Taabir's Board Decision Matrix already is this chart. It defines exactly where staff autonomy ends, where staff consultation is required, and where Board authority begins, and it does this proactively rather than case by case. The Community Connector can make outreach decisions without checking in first. The Fellows can make program decisions inside their own domains. The Board only steps in at thresholds that were defined ahead of time, not thresholds it decides on the spot. That's the protection: nobody has to be everywhere, because the map of where each person's authority actually lives was drawn before the decisions that would test it.
