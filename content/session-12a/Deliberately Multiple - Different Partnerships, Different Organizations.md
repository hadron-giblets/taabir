# Deliberately Multiple: Different Partnerships, Different Organizations

Different partnerships end up creating different versions of the same organization. A resource center answering to city funding has to use business-as-usual methods: eligibility screenings, outcome metrics, documentation that ends up excluding undocumented community members almost by default. A resource center running purely on community trust can serve anyone, document minimally, and respond to what a person actually needs without a bureaucratic filter sitting between them.

The strategic implication is that Taabir may need to be deliberately more than one thing at once: a city-facing organization able to accept public funding for certain programs, and a community-facing organization operating below the documentation threshold for others. The café can be a permitted, inspected, conventional business. The welcoming room can be free, undocumented, and completely open. The vocational school might take city workforce vouchers for some seats while offering free, no-questions-asked training for others.

None of this is inconsistency. It's a recognition that the version of Taabir a funder sees and the version a community member walks into don't have to be identical to both be honest.
